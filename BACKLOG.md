# Consilium — бэклог

Живые задачи и отложенные находки. Сделанное уходит в историю коммитов, `[x]` здесь не копим.

## Открытое

Открытых задач нет.

## Решения

- **«Стоп» при закрытии проекта сохраняет обрезок ответа** с пометкой, как и ручной «Стоп»: иначе
  после перезапуска IDEA он пропадёт.
- **Ход «делает» всегда в новой сессии**, а сессия обсуждения этого агента после него сбрасывается:
  следующее обсуждение начинается с полного транскрипта и видит отчёт о правках. Продолжать сессию
  обсуждения в «делает» нельзя: у `codex exec resume` песочница не задаётся флагом.
- **Claude в обсуждении работает с `--restricted`.** Файлы настроек пользователя и проекта в ходах
  обсуждения не читаются: иначе чужой репозиторий мог бы запустить свой хук в «только чтении». Из
  личного `~/.claude/settings.json` обратно через `--settings` передаются только модель, усилие,
  `env` и помощники входа (`ClaudeUserSettings.KEPT_KEYS`) — файлом с правами 600, а не строкой:
  в `env` бывают ключи, а аргументы видны всем через `ps`. `--settings` под `--restricted`
  действует — проверено 2026-11-10 на Claude Code 2.1.322.
- **Codex в обсуждении выключает все свои MCP-серверы поимённо** (`-c mcp_servers.<имя>.enabled=false`
  по списку `codex mcp list --json`): MCP работают вне песочницы. Сервер с именем не из
  `[A-Za-z0-9_-]` выключить флагом нельзя — codex-cli 0.167.0 не понимает кавычки в пути `-c`, —
  поэтому такой ход не запускается, а не идёт с работающим сервером. `--ignore-user-config` не берём:
  он сбрасывает и модель, и профиль.
- **Окружение IDE передаётся агентам целиком.** CLI нужны не только ключи API, а надёжного списка
  «лишних секретов» нет; чистка ломала бы вход и прокси. Агенту «делает» доверяют так же, как
  терминалу.
- **«Контекст редактора» включён по умолчанию.** Галочка на виду рядом с «Отправить», и её смысл —
  экономить вопрос «какой файл?». Что уходит агентам, написано в README.
- **Плагин не подписан и не публикуется в Marketplace.** Раздаём ZIP из GitHub Releases; подпись
  (`signPlugin`) и проверка совместимости (`verifyPlugin`) нужны вместе с публикацией в Marketplace.
- **Чекбоксы задач (`- [x]`) показываются обычными пунктами списка:** `<input>` в ответах агентов
  не пропускается санитайзером.
- **Режим «Авто» понимает фразу отдельным вызовом Claude без инструментов**, который видит только
  сообщение человека, не транскрипт: право на запись не должно зависеть от текста агентов. Модель —
  умолчание пользователя: на наборе из 56 фраз (`src/test/resources/intent/labeled.tsv`) она дала
  56/56 и ~2 с, haiku — 54/56 и не быстрее (замер 2026-11-10). Явно `opus` не ставим: на Bedrock или
  командном плане такого псевдонима может не быть, и каждое сообщение молча стало бы обсуждением.
  Повторить замер: `CONSILIUM_LIVE_EVAL=1 ./gradlew test --tests '*IntentLiveEvaluationTest' --rerun`.
- **Задача без имени («поправь README») идёт одному Claude**, оба работают только по явному
  «делайте вдвоём / каждый свою часть»: два агента над одной задачей без раздела дали бы две
  конфликтующие копии.
- **Части параллельной задачи коммитит Consilium, а не агенты.** Codex в копии не получает права
  писать в `.git` репозитория: через `--add-dir` на `.git` он мог бы записать хук или
  `core.fsmonitor` и выполнить код вне песочницы при следующей git-команде (находка ревью
  2026-11-10). Заодно агентам не нужны правила коммитов репозитория (номер задачи и т. п.):
  сообщения по правилам пишет сводящий агент.
- **Одна параллельная задача за раз; «Clear» не трогает несведённую работу.** Новая задача
  поверх несведённых частей похоронила бы их, а «Clear» с `--force` удалил бы незакоммиченное.
- **Сведение ждёт чистого проекта.** Правки человека, сделанные, пока агенты работали, не должны
  уехать в stash или в merge-коммит: Consilium просит закоммитить или убрать их и сказать «сведите».
- **Вставленный текст — слова человека.** Вставленная просьба («please fix X») может прочитаться как
  задача; это осознанно: право на запись даёт сообщение человека, а не агента.
- **Сводит Claude**, если человек не назвал другого («Codex, сведи»). Сведение запускается само,
  только когда обе части закончились ответом и в обеих есть коммиты; иначе работа остаётся в ветках
  до «сведите». Копии убираются после сведения; копия с незакоммиченными правками и несведённая
  ветка остаются, ничего не теряется молча.
- **Длинная история открывается порциями по 25 карточек**, IDE при этом не замирает. Отдельный замер
  не делали: порции снимают вопрос при любом размере транскрипта.
- **Транскрипт режется до 300 сообщений между ходами**, а не во время хода: индексы `seenThrough`
  живых ходов не должны сдвигаться.
