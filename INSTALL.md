# Consilium 0.2.0 — установка

В этой папке лежит готовый плагин для IntelliJ IDEA 2026.1.

## Как установить

1. Открой IntelliJ IDEA.
2. Перейди в **Settings → Plugins**.
3. Нажми шестерёнку **⚙ → Install Plugin from Disk…**.
4. Выбери лежащий рядом файл `consilium-idea-plugin-0.2.0.zip`.
5. Перезапусти IDEA.
6. Справа открой Tool Window **Consilium**.

## Как пользоваться

- **Оба обсуждают** — Claude и Codex независимо отвечают на одно сообщение и видят общий разговор на следующем ходе.
- **Claude отвечает / Codex отвечает** — вопрос получает только выбранный агент.
- **Claude делает / Codex делает** — выбранный агент читает и изменяет проект, запускает проверки и отчитывается; второй агент на этом ходе не запускается.
- **контекст редактора** — прикладывает путь открытого файла и выделенный текст.
- **Стоп** — останавливает текущий ответ.
- **Очистить** — начинает новый локальный разговор.

Consilium использует уже установленные и авторизованные `claude` и `codex` CLI. Их настройки, навыки и MCP сохраняются.
